# ☕ CoffeeCup – Flutter E-Commerce App

Tagline: One Tap. One Cup. Pure Comfort.

CoffeeCup is a Flutter-based Android e-commerce application designed for a coffee shop.
It allows users to browse coffee and dessert items, manage cart and wishlist, place orders, and view order history with a smooth and animated user interface.

This project was developed as an End Semester Project for Mobile App Development.

# 📱 App Overview:

CoffeeCup provides a modern shopping experience with:

Animated UI

Dark & Light themes

Guest mode support

Smooth navigation and product zoom effects.

# ⚙️ Implementation Steps:
## 1️⃣ Clone the Repository:
    git clone https://github.com/USERNAME/coffeecup-flutter-app.git
    cd coffeecup-flutter-app

## 2️⃣ Install Dependencies:
    flutter pub get

## ▶️ Run on Android Emulator:

🔹 Prerequisites

Flutter SDK installed

Android Studio installed

Android Emulator created

🔹 Steps

Open Android Studio

Go to Device Manager

Start an Android Emulator

In VS Code terminal, run:

flutter run


Flutter will automatically detect the emulator and launch the app.
